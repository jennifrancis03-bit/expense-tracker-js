# Expense Tracker JS

Simple assignment implementing expense tracking logic in JavaScript.

What I completed:
- Declared six expense variables (`rent`, `food`, `transport`, `internet`, `entertainment`, `utilities`).
- Flagged individual high spending (over $100) using conditional statements.
- Stored expenses in an array and calculated the total with a loop.
- Implemented a monthly income comparison to report budget status.

All output is printed to the browser console. See `index.html` and `script.js`.
